> [!NOTE]
> # REVISED EDITION & FAN PROJECT
> **Metrolist Music** is an independently customized and modified software edition built upon the original Metrolist client architecture.
> - **Original Lead Developer**: [Mo Agamy](https://github.com/mostafaalagamy) ([Metrolist Repository](https://github.com/MetrolistGroup/Metrolist))
> - **Secondary Developer (Revised Edition)**: Nguyen Minh Toi (Assisted by Google AI Studio)
>
> This customized build introduces a fully overhauled interface, refined interaction workflows, and integrated endpoint configuration features while fully retaining the open-source code base integrity.

> [!WARNING]
> # MAINTENANCE MODE
> Metrolist Music is currently operating in maintenance mode. Active engineering focus is directed strictly toward system stability, critical security patches, and essential UI polish.

<h2><a id="features"></a>Features</h2>

| Playback & Audio Controls | Library & Personalization |
| :--- | :--- |
| • High-fidelity audio and video streaming<br/>• Background playback with local caching<br/>• Dynamic silence skipping & sleep timer<br/>• Equalizer support, pitch, & tempo controls<br/>• Audio normalization & level balancing | • Playlist import and queue customization<br/>• Native connection link support<br/>• Account synchronization for library assets<br/>• Real-time lyrics with automated translation<br/>• Comprehensive music search & discovery |

<br/>

| Interface & Visuals |
| :--- |
| • **Overhauled, modern interface design**<br/>• Native home screen widget support<br/>• Dynamic Material 3 color engine (Light, Dark, OLED Black) |
