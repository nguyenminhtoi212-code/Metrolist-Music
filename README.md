> [!NOTE]
> # REVISED EDITION & FAN PROJECT
> **Metrolist Music** is an independently modified audio client based on the core architecture of the original Metrolist application.
> - **Original Lead Developer**: [Mo Agamy](https://github.com/mostafaalagamy) ([Base Project Repository](https://github.com/MetrolistGroup/Metrolist))
> - **Revised Client Developer**: Nguyen Minh Toi (Assisted by Google AI Studio)
>
> This release offers an enhanced interface design, tailored client workflows, and flexible local endpoint settings while preserving full open-source integrity.

> [!WARNING]
> # MAINTENANCE STATUS
> This application is currently operating in active maintenance mode. Ongoing updates prioritize client stability, interface polish, and performance optimizations.

<h2><a id="features"></a>Key Features</h2>

<table>
  <tr>
    <td width="50%" valign="top">

#### Playback & Sound Engine
- Stream tracks and video streams smoothly
- Comprehensive background playback & offline caching
- Automated silence skipping & adjustable sleep timer
- Audio normalization, tempo tuning, and pitch control
- Integrated graphic equalizer controls

</td>
    <td width="50%" valign="top">

#### Library & Management
- Structured playlist organization (Local & Imported)
- Configurable connection parameters
- Seamless library synchronization
- Synchronized live lyrics with AI translation support
- Personalized quick recommendations & global search

</td>
  </tr>
  <tr>
    <td width="50%" valign="top">

#### User Interface
- **Redesigned interface layout and navigation flow**
- Interactive home screen widgets
- Light, Dark, and OLED Pitch Black display themes
- Material 3 dynamic color scheme palette integration

</td>
    <td width="50%" valign="top">

#### Social
- Real-time Listen Together session features

</td>
  </tr>
</table>
