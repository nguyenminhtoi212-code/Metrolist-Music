> [!NOTE]
> # ABOUT THIS EDITION
> **Metrolist Music (Mod Edition)** is a community-driven, custom-modified version of the original Metrolist music client. 
> 
> While maintaining 100% open-source code integrity, this edition features a **completely overhauled user interface**, refined design aesthetics, and additional backend connection flexibility.

> [!WARNING]
> # MAINTENANCE STATUS
> The core Metrolist upstream is currently in maintenance mode. This repository focuses on UI/UX evolution, custom endpoint connectivity, and ongoing stability updates.

<h2><a id="features"></a>Key Features Overview</h2>

| Feature Category | Included Capabilities |
| :--- | :--- |
| 🎵 **Playback & Streaming** | Background audio playback, full track/video audio streaming, offline caching, silence skipping, and sleep timer. |
| 🎚️ **Audio Enhancements** | Dynamic normalization, real-time tempo/pitch adjustment, and customizable equalizer controls. |
| 🎤 **Lyrics & Discovery** | Live synchronized lyrics, AI-driven lyrics translation, personalized quick picks, and multi-category search. |
| 📚 **Library & Sync** | Comprehensive playlist management, local file import, queue reordering, and custom server/connection link support. |
| 🎨 **Redesigned Interface** | Overhauled UI design, Material 3 dynamic color palettes, widgets, and AMOLED/Dark/Light theme modes. |
| 👥 **Social Connection** | Real-time "Listen Together" synchronized playback functionality. |
