> [!NOTE]
> # FAN VERSION & MODIFIED EDITION
> Metrolist Music is a modified, custom edition built upon the foundation of the original Metrolist client.
> - **Original Lead Developer**: [Mo Agamy](https://github.com/mostafaalagamy)
> - **Mod Developer**: Nguyen Minh Toi (Assisted by Google AI Studio)
>
> Users can choose to download either the official build or this enhanced edition, which features custom server links, flexible connection options, and an upgraded interface experience while staying true to its open-source core.

> [!WARNING]
> # MAINTENANCE MODE
> Metrolist is currently in maintenance mode. Only essential bug fixes and minor stability updates will be processed.

<h1><a id="key-features"></a>Key Features</h1>

<table>
  <tr>
    <td width="50%" valign="top">

#### 🎵 Playback & Audio
- Seamless track and video audio streaming
- Background playback and offline caching
- Built-in silence skipping & sleep timer
- Dynamic audio normalization
- Custom tempo, pitch, and equalizer controls

</td>
    <td width="50%" valign="top">

#### 📜 Lyrics & Discovery
- Real-time synchronized lyrics
- AI-powered live lyrics translation
- Intelligent quick picks and music recommendations
- Comprehensive search for tracks, albums, artists, and playlists

</td>
  </tr>
  <tr>
    <td width="50%" valign="top">

#### 📚 Library & Custom Server
- Full-featured library & queue management
- Local music file importing
- Custom connection server URLs & endpoint configuration
- Multi-device sync for saved playlists, artists, and albums

</td>
    <td width="50%" valign="top">

#### 🎨 Interface & Social
- Real-time **Listen Together** room support
- Material 3 dynamic palette integration
- Customizable themes: Light, Dark, AMOLED Black, and Dynamic
- Home screen widget support

</td>
  </tr>
</table>
