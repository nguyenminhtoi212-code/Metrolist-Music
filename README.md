> [!NOTE]
> # FAN EDITION & MODIFIED VERSION
> Metrolist Music is a redesigned, modified fan-made edition based on the original Metrolist client.
> - **Original Lead Developer**: [Mo Agamy](https://github.com/mostafaalagamy)
> - **Modified Edition Maintainer**: Nguyen Minh Toi (Assisted by Google AI Studio)
>
> While fully maintaining open-source integrity, this edition features a completely overhauled UI design, personalized interface enhancements, and custom endpoint connection capabilities.

> [!WARNING]
> # MAINTENANCE MODE
> Metrolist is currently in maintenance mode. Only essential bug fixes and critical stability updates will be provided.
