> [!NOTE]
> ### 🎨 Modified Fan Edition
> **Metrolist Music** (Mod Edition) is an enhanced, community-maintained fork of the original Metrolist client.
> - **Original Lead Developer**: [Mo Agamy](https://github.com/mostafaalagamy)
> - **Mod Maintainer**: **Nguyen Minh Toi** *(Assisted by Google AI Studio)*
>
> This modified build introduces custom connection URLs and enhanced user interface options while maintaining 100% full compatibility with the original open-source core.

> [!WARNING]
> ### 🛠️ Maintenance Status
> The upstream repository is currently in **maintenance mode**. Focus is primarily placed on stability patches, essential bug fixes, and minor performance improvements.

## 🌟 Key Features

<table>
  <tr>
    <td width="50%" valign="top">

#### 🎵 Playback & Audio
- Seamless track & audio stream playback
- Full background audio support
- Offline listening with local caching & downloads
- Built-in silence suppression & sleep timer
- Dynamic audio normalization, tempo/pitch shift, and equalizer

</td>
    <td width="50%" valign="top">

#### 🎼 Lyrics & Discovery
- Real-time synchronized lyrics
- AI-driven dynamic lyrics translation
- Smart personalized quick-picks
- Comprehensive search for tracks, albums, artists, and playlists

</td>
  </tr>
  <tr>
    <td width="50%" valign="top">

#### 📚 Library & Sync
- Complete music library management
- Local playlist import and queue reordering
- Custom server connection URLs for account login
- Instant cross-device cloud sync for saved content

</td>
    <td width="50%" valign="top">

#### 🎨 Design & Social
- Real-time *Listen Together* session support
- Dynamic Material 3 design and color palettes
- Customizable Light, Dark, True-Black, and Dynamic themes
- Home screen widget support

</td>
  </tr>
</table>
